Security First

Built for the age of AI agents

When AI agents have terminal access, .env files and environment variables are an open book. EnvSave changes the game.

AES-256-GCM Encryption

Your vault is encrypted with military-grade AES-256-GCM. PBKDF2 with 100,000 iterations derives the key from your master password. No plaintext, ever.

Opaque Key System

Secrets are accessed via HMAC-derived opaque keys like es_7a3f2b1e9c. Even if an agent sees the key, it reveals nothing about the secret name or value.

Node.js + Python

Native TypeScript library and Python bridge read the same encrypted vault. One vault file for all your projects — no duplication.

Cloud Backup & Sync

Encrypted vault backups to the cloud. Your data is always encrypted — the server never sees plaintext. Sync across machines with a single command.

Drop-in .env Replacement

Import your existing .env file in one command. EnvSave encrypts everything and generates opaque keys automatically. Zero code changes needed.

Session Isolation

A session-scoped cache with a random key means your secrets are only accessible while the vault is unlocked. Kill the session, secrets disappear from memory.

Quick Start

Up and running in 60 seconds

Three steps from .env insecurity to encrypted vault protection.

Install & Activate

Install globally with npm. Sign up here for a free license token, then activate it on your machine.

Import Your Secrets

Run envsave init --env .env to import all your environment variables. Each secret gets a unique opaque key.

Use in Your Code

Replace process.env.KEY with envsave.get("es_..."). Your secrets are now invisible to bulk discovery.

Backup to Cloud

Run envsave backup to sync your encrypted vault. Always encrypted end-to-end — we never see your data.

Developer Experience

Simple API, powerful protection

Two lines of code to fetch a secret. Works in Node.js and Python.

app.ts 
import envsave from "envsave";

// Fetch secret by opaque key
const apiKey = envsave.get("es_7a3f2b1e9c8d4f6b");

// Check if a key exists
if (envsave.has("es_7a3f2b1e9c8d4f6b")) {
  console.log("Secret loaded");
}

// Falls back to process.env automatically
const port = envsave.get("PORT");
terminal 
# Initialize vault from .env
$ envsave init --env .env

# See your opaque keys

# Backup to cloud

# Sync across machines
$ envsave sync
