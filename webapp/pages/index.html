eVault

Local secret vault for LLM-safe environments.
Encrypted secrets that AI agents can't bulk-discover.

AES-256-GCM Encryption

Secrets stored in a binary encrypted vault file. PBKDF2 with 100k iterations derives the key from your master password. No plaintext anywhere.

LLM-Safe by Design

Unlike .env files, LLM agents can't run printenv or read os.environ to discover your secrets. Programs fetch secrets one-by-one via the API.

Node.js + Python

Native library for Node.js and a Python bridge — both read the same encrypted vault file. One vault, all your projects.

# Install and initialize
npm install -g evault
evault activate <your-token>
evault init --env .env

# Use in your code
const evault = require('evault');
const key = evault.get("OPENAI_API_KEY");
